I built this AI-powered SEO system that improves search rankings and increases organic traffic.

It researches keywords, analyses competitors, creates and publishes SEO articles, and recommends backlink opportunities.

Here’s how it works:

Every week, the system triggers a Keyword Research Agent that uses DataForSEO to research relevant keywords based on a company’s niche and industry. The agent scores and filters the keywords based on factors like search volume, keyword difficulty, and search intent to identify opportunities worth targeting. 

Next, the Competitor SERP Analysis Agent analyses the top-ranking pages for each selected keyword.

It identifies:
→ Content gaps
→ Recommended topics and headings
→ Opportunities to create more comprehensive content

Next, the SEO Content Creation Agent uses these insights to create an SEO-focused blog post, structured to support both traditional SEO and AEO.

It then repurposes the content into:
→ A LinkedIn post
→ A newsletter

Before anything gets published, a human-in-the-loop approval process allows the content to be reviewed and sent back for revision if needed. Once approved, the system publishes the content. 

Finally, the Backlink Recommendation Agent researches relevant backlink opportunities and saves the recommendations to the database. 

Each stage uses a specialized AI agent. Under the hood, it runs on a deterministic pipeline, making the system predictable and cost-efficient to run.

Stack: n8n, DataForSEO, OpenAI, Gemini, Google
